# Before the Detector

Repository containing files \& code relevant to the COSE paper "Before the Detector: Can Public Gaming Data Expose the Hidden Laundromat?" by Dr. Stephen Flowerday, Emil Eminov, Dmitri Kharchevnikov, and Ty Bingham.



##### This repository contains:

* COSE\_Main\_Code\_Reviewer\_Answers\_25Nov2026
* 02\_Emil\_Timestamps\_Plans
* 03\_Ty\_Reproducibility\_Data
* 04\_Ty\_Figures\_2\_\&\_3\_Code
* COSE\_Supplementary\_Material



Each folder has a README file inside of it to explain its contents.
